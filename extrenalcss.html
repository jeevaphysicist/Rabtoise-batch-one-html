Selectors tell CSS which element to target. Element selector targets all elements of that type — p targets all paragraphs. Class selector targets elements with a matching class — .card styles all elements with class='card'. ID selector targets one unique element — #header. Descendant selector targets elements inside another — .nav a targets all links inside .nav. Key rule: use classes for CSS, use IDs for JavaScript — never use the same ID twice on a page.
